# Future Events Tracker

## Быстрый запуск

### Backend

```bash
python -m uvicorn app.main:app --reload
```

Документация API будет доступна по адресу `http://127.0.0.1:8000/docs`.

### Frontend

```bash
cd frontend
npm.cmd install
npm.cmd run dev
```

Клиент будет доступен по адресу `http://127.0.0.1:5173`.
